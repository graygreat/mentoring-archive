# 2026-11-12 · 교재 검증 읽기와 CRUD 설계

## 네 교시

각45분 활동+15분 휴식·정리입니다. 앞2교시는 CH10 도메인·컨트롤러 검증, 전역예외핸들러, 상태·바디를 책에서 읽고 적용합니다. 뒤2교시는 CH09 수정·삭제와 CH12 리팩토링·테스트, 부록B 문서화 흐름으로 `product-api/docs/crud-design.md`를 작성합니다. 판본에서 관련 쪽수를 표시하며 수업의 HTTP 계약을 책 원문과 혼동하지 않습니다. 강사 코딩 시연은 하지 않습니다.

## 실제 확인

빈이름·누락/null·음수가격400, 가격0정상, 없는상품404, 실패후원본보존을확인합니다. 기존정상POST/GET은유지합니다. `Product`규칙은DTO검증을추가해도제거하지않습니다. 기존선택검색기능이있으면`findAll`검색코드를그대로보존합니다. `Integer price`와`@NotNull`을유지합니다.

HTTP 메서드·상태·멱등성과 REST성숙도는 책의 기술면접TIP을 읽고 자기API로설명하는질문으로만확인합니다. 프레젠테이션에서긴암기강의를하지않습니다. 반복DELETE의상태코드와최종부재상태는구분합니다.

## 14일 설계 산출물

PUT은 기존id를유지하며200과수정상품을반환하고,없는id404·잘못된입력400으로정합니다. DELETE는204/본문없음,없는id404로정합니다. 실패전후원본,가격0,동일값수정,삭제후조회사례를설계합니다. 이는수업에서정한계약이며교재와다르면근거·가정으로표시합니다.
