SPRING BOOT & AI관계 매핑

owner 객체 참조와 owner_id 컬럼 연결

// ShortLink 내부 · 다른 필드와 기본 생성자 생략
@ManyToOne(fetch = FetchType.LAZY, optional = false)
@JoinColumn(name = "owner_id", nullable = false)
private AppUser owner;
설정이 예시에서의 뜻
@ManyToOne여러 링크가 같은 사용자 한 명을 참조 가능
@JoinColumn(name = "owner_id")연결 값을 저장할 FK 컬럼 이름
FetchType.LAZY관계 데이터의 조회를 필요할 때까지 미루도록 설정
Java에는 AppUser owner, DB에는 owner_id 값이 있습니다.
optional=false는 필수 관계, nullable=false는 FK 컬럼의 null 불허 매핑입니다.
