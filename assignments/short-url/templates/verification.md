# 단축 URL 검증 기록

실행일/환경/실제 포트/커밋:

## 백엔드

| 사례 | 준비·요청 | 기대 | 실제 | 근거 |
| --- | --- | --- | --- | --- |
| 정상 생성 | 실제 JSON 작성 | 명세와 일치 | 미실행 | |
| 원본 이동 | 위 응답의 실제 코드 | 설계한 3xx와 원본 Location | 미실행 | |
| 빈/공백 URL | 각각 별도 요청 | 명세와 일치 | 미실행 | |
| 잘못된 주소/금지 스킴 | 각각 별도 요청 | 거부·저장 상태 불변 | 미실행 | |
| 없는 코드 | 현재 저장소에 없는 코드 | 명세와 일치 | 미실행 | |
| 중복·충돌 | 본인 정책과 재현 방법 | 정책과 일치 | 미실행 | |
| 재시작 | 생성 후 서버 재시작 | 메모리는 초기화 | 미실행 | |

- 테스트 명령/실제 결과/실패 수정:
- 이동 응답은 자동 리다이렉트 옵션을 끄고 상태/Location을 먼저 확인합니다. 실제 브라우저 이동은 별도로 확인합니다.

## AI 기록

사용 도구/모델(확인 가능 시)/날짜/입력 프롬프트/받은 초안/직접 고친 곳/검증 근거를 docs/ai-log.md에 기록합니다. AI 출력 전체를 검증 완료로 간주하지 않습니다.
