# 11월 19일 대강 진행표 — 이준형 강사

## 수업 목표와 출발 상태

4시간 전체를 16일 학습 내용을 적용하는 자율 실습으로 진행한다. 새 개념 강의와 강사 구현 시연은 하지 않는다. 책의 상품 관리가 공통 프로젝트이며, 단축 URL 과제 구현 여부는 본 실습 진행 조건이 아니다.

학생은 상품 CRUD·DTO·검증·예외 처리가 완성된 메모리 API와 ProductEntity·SpringDataProductRepository·JPA 저장소 테스트를 가지고 온다. 출발 코드 ZIP은 동일한 16일 상태다. 오늘 결과는 기존 ProductRepository를 구현한 Jpa adapter를 연결하는 것이다.

준비물: [멘티 작업지](STUDENT-WORKSHEET.md), [출발 ZIP](assets/product-api-start.zip), [참고 슬라이드](index.html), [강사 참고](INSTRUCTOR.md). 시작 전 ZIP을 별도 폴더에 풀고 `./gradlew test`가 통과하는지 확인한다. 네트워크가 불안하면 의존성 다운로드를 사전에 완료한다.

## 시간별 진행

| 블록 | 학생 작업 | 강사 확인 지점 |
|---|---|---|
| 1: 작업 45분 + 휴식 15분 | 책 데이터 접근 부분 재확인, 출발 빌드, API 계약 기록, 변경 계획 | 기존 실패와 새 변경 문제 분리, Memory가 현재 API 구현체임을 설명 |
| 2: 작업 45분 + 휴식 15분 | Jpa adapter, 빈 선택, Service 트랜잭션 연결 | 구현체 빈 1개, 실제 id, 정렬, update/delete 계약, OSIV false |
| 3: 작업 45분 + 휴식 15분 | 정상·실패 API 회귀, JPA 전환 테스트 | HTTP 상태만 아니라 실패 전후 데이터 비교, 실제 id 사용 |
| 4: 작업/점검 45분 + 제출 정리 15분 | 파일 DB 재시작, README/Wiki, PR | 같은 id·수정 값 유지, 테스트, PR·Wiki 증거 |

매 블록 5분 전 완료 기준을 읽고 학생에게 결과를 보여달라고 요청한다. 4교시의 마지막 15분은 새 구현보다 제출 상태와 남은 작업 기록에 사용한다. 진도가 밀리면 선택 과제는 생략한다.

## 도움 순서

1. 오류 문장, 재현 명령, 기대 결과를 학생에게 설명하게 한다.
2. 작업지 1단계 힌트로 파일·메서드 계약을 찾게 한다.
3. 2단계 힌트로 빈·변환·트랜잭션·환경을 좁힌다.
4. 계속 막히면 강사 참고 구현의 해당 부분만 비교한다. 전체 정답 복사를 첫 해결책으로 삼지 않는다.

복구 ZIP은 임시 폴더에서 실행·비교한다. 기존 코드와 파일 DB를 덮어쓰지 않는다. 학생이 실제로 적용한 변경과 복구본 사용 범위를 기록하도록 한다. 시간이 부족해도 DB 삭제로 보존 검증을 건너뛰지 않는다.

## 증상별 확인

| 증상 | 확인·조치 |
|---|---|
| ProductRepository 빈 후보가 2개 | Memory의 @Repository 제거, Jpa만 등록. @Primary를 임시로 붙여 중복을 감추지 않음 |
| 빈을 못 찾음 | Jpa 클래스 package·@Repository·컴포넌트 스캔 범위 확인 |
| 테이블 없음/다른 DB 조회 | 실행 datasource URL·프로필·DDL·현재 폴더 확인 |
| DB 파일 잠금 | 같은 파일 DB에 연결된 실행 프로세스를 정상 종료 |
| 수정 200인데 DB 값은 원래대로 | Service 트랜잭션·관리 Entity 변경·재조회 확인 |
| 테스트만 통과, 실제 앱 재시작 실패 | 인메모리 테스트와 파일 실행 DB를 구분 |
| 재시작 후 데이터 사라짐 | create/create-drop/메모리 URL/폴더 변경 확인. 파일 삭제 금지 |
| 입력 오류가 400 대신 다른 실패로 바뀜 | Service create/update의 Repository 호출 전 도메인 검증 보존 확인 |
| 긴 이름만 DB 저장 실패 | 기존 API 길이 계약·Entity name의 @Lob·긴 이름 저장 테스트 확인 |
| 컨트롤러 응답 바뀜 | DTO 반환·예외 처리·기존 API diff 확인 |
