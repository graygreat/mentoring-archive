## 책과 보충 실습의 구분

교재 CH 11 「상품 관리 애플리케이션에 데이터베이스 연동하기」에서 DB 접근과 저장·조회 흐름을 읽습니다. 교재의 JDBC 접근과 수업의 JPA 구현은 다릅니다. CH 12의 추상화·테스트와 연결하되, 교재에 없는 JPA 절이나 쪽수를 만들지 않습니다. 실제 판본에서 읽을 절을 표시합니다.

## 유지할 실행 경계

- 오늘 JPA 테스트: ProductEntity → SpringDataProductRepository → 독립 테스트 DB, 기본 rollback.
- 오늘 실제 HTTP: Controller → Service → MemoryProductRepository. 기존 CRUD·400·404는 유지합니다.
- main 파일 DB 설정은 19일 API 전환에 사용합니다. JPA 테스트 성공이 API의 DB 전환이나 재시작 보존을 뜻하지 않습니다.
- Product 도메인과 JPA Entity를 구분합니다. 기존 ProductRepository와 새 SpringDataProductRepository를 연결할 Adapter는 19일 작성합니다.
- `flush`는 SQL 전송, `commit`은 확정, `clear`는 관리 객체를 비우는 동작입니다. 작업지의 실행 결과와 함께 설명합니다.
- 기존 예제의 긴 이름 매핑·300자 왕복 테스트는 기존 API 계약을 보존하기 위한 수업 선택입니다. 새 이름 길이 제한을 추가하지 않습니다.

전체 Java 참고 파일은 PPT 마지막 자료 화면에서 선택해 확인합니다. `source-data`는 기존 `code_examples.py` 원문과 동일하며, 본문에 코드를 14줄씩 나누어 강의하지 않습니다. 참고 코드는 교재 복제가 아닌 수업 독립 예제입니다.
